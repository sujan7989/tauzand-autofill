# Tauzand AutoFill AI

> AI-powered Chrome Extension that automatically fills job application forms from your uploaded resume.

[![Backend](https://img.shields.io/badge/Backend-Render-46E3B7?logo=render)](https://tauzand-autofill.onrender.com/api/health)
[![Python](https://img.shields.io/badge/Python-3.11-blue?logo=python)](https://python.org)
[![Flask](https://img.shields.io/badge/Flask-2.3-black?logo=flask)](https://flask.palletsprojects.com)

---

## What It Does

Upload your resume once. The extension reads it, extracts your profile, and automatically fills job application forms across supported platforms and any unknown job site.

- **No hardcoded data** — every value comes from your uploaded resume
- **No fabrication** — if a field value is not in your resume, it is left blank
- **AI answers** — open-ended questions (cover letter, why join, tell me about yourself) are answered using your resume + the job description
- **Works offline** — deterministic fields fill without AI calls

| `GET /api/v1/ai/health` | AI service status |

## Install Extension

1. Open Chrome → `chrome://extensions/`
2. Enable **Developer mode** (top right toggle)
3. Click **Load unpacked** → select the `extension/` folder from this repo
4. The extension icon appears in your toolbar — no backend setup needed

---

## How to Use

1. Click the extension icon
2. Upload your resume (PDF or DOCX)
3. Go to any job application page
4. Click **Scan Page** → then **Autofill**

Or use **Quick Autofill** to skip the scan step on known sites.

## Deploy Your Own Backend

The backend is already deployed. If you want your own instance:

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/sujan7989/tauzand-autofill)

After deploying, add these environment variables in the Render dashboard:

| Variable | Description |
|---|---|
| `SUPABASE_URL` | Your Supabase project URL |
| `SUPABASE_KEY` | Supabase anon public key |
| `SUPABASE_SERVICE_KEY` | Supabase service role key |
| `NVIDIA_NIM_API_KEY` | NVIDIA NIM API key (for AI answers) |
| `SECRET_KEY` | Auto-generated by Render |
| `JWT_SECRET_KEY` | Auto-generated by Render |

Then update the backend URL in the extension Settings to your new URL.

## Architecture

```
Resume (PDF/DOCX)
       |
       v
 Flask Backend (Render)
 /api/profile/upload
       |
       v
 Resume Parser
 - Extracts: name, email, phone, location, skills,
   experience, education, LinkedIn, GitHub, etc.
       |
       v
 Chrome Storage (browser-local)
       |
       v
 Content Scripts
 - detectForms.js    → find all form fields
 - extractHTML.js    → send to backend for analysis
 - shared.js         → helpers (fillField, showToast, getAIAnswer)
       |
       v
 Platform Router (background.js)
 - Known site  → dedicated adapter (Workday/Greenhouse/etc.)
 - Unknown site → Universal Engine (autoFill-universal.js)
       |
       v
 Field Fill
 - interaction-strategies.js → per-component fill strategy
 - autoFill-universal.js     → DETECT → CLASSIFY → MAP → FILL → VERIFY
       |
       v
 Post-fill Verification (verifier.js)
 - Checks aria-invalid, error messages, required fields
 - Shows warnings in popup if fields need attention
```

## Notes

- Free tier on Render spins down after 15 minutes of inactivity. The extension pings the backend every 10 minutes to keep it alive.
- Resume data is stored only in the browser's `chrome.storage.local` — not sent to any third party.
- All AI answers are grounded in the uploaded resume. Facts not present in the resume are not invented.
